# C++ 练习

自己刷题、练语言特性写的，按主题分目录。单文件、无第三方依赖。

| 目录 | 内容 |
|---|---|
| `力扣/` | LeetCode 题解（滑动窗口、链表、矩阵、哈希、二分） |
| `算法/` | 手写数据结构与排序：二叉排序树、AVL、B 树、红黑树、四种排序 |
| `线程/` | 并发：`condition_variable`、原子操作、`async`、线程池、智能指针、完美转发 |
| `STL练习/` | 容器用法 |
| `复习/` | 语法复习（多态、STL、string） |
| `洛谷/` | 洛谷题 |

编译：`g++ 文件名.cpp -std=c++17 -pthread`

改完代码双击 `推送到GitHub.bat` 就传上去。
