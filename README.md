# C++ 练习

刷题和语言特性的练习代码，按主题分目录。都是单文件、能独立编译的 `.cpp`，
没有工程依赖、没有第三方库，一个 `g++` 就能跑。

## 目录

| 目录 | 内容 |
|---|---|
| `力扣/` | 29 道 LeetCode 题解，文件名就是题目（滑动窗口、链表、矩阵、哈希、二分） |
| `算法/` | 14 个：二叉排序树、AVL、B 树、红黑树，以及快排 / 归并 / 插入 / 选择排序 |
| `线程/` | 11 个：`condition_variable`、互斥量、原子操作、`async`、单例、智能指针、跨平台线程池；还有左值右值 / 引用折叠 / 万能引用 / 完美转发那一组 |
| `STL练习/` | 13 个：string、vector、list、deque、set、stack / queue，外加「评委打分」这类小案例 |
| `复习/` | 7 个：多态、STL、string |
| `洛谷/` | 4 个：过河卒、铺地毯 |

## 怎么编译

单个文件，不需要 CMake：

```bash
g++ 力扣/1两数之和.cpp -std=c++17 -o out
./out
```

`线程/` 下的用到 `std::thread`，Windows 上的 MinGW 要加 `-pthread`：

```bash
g++ 线程/跨平台线程池.cpp -std=c++17 -pthread -o out
./out
```

我这边是 MinGW-w64 g++ 15.2.0，标准用 `-std=c++17`。
`线程/左值右值极其引用，引用折叠，万能引用，完美转发.cpp` 用到了折叠表达式，
低版本的 g++ 可能编不过。

仓库里没有 `.vscode/` —— 原来的 `tasks.json` 把 g++ 和 gdb 的路径写死成了本机的 MinGW 目录，
别人拿去用不了，所以没放进来。自己配一下编译命令就行。
